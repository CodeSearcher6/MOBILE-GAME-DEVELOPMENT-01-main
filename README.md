# City Runner

A 3D endless runner for Android, built in Unity with C#. The player dashes
through a procedurally generated city, dodging obstacles that keep coming faster.

<img width="1023" height="574" alt="image" src="https://github.com/user-attachments/assets/d41758c2-bc77-452c-864b-50755ed4b055" />

## Features
- Endless, procedurally generated obstacle course
- Physics-based movement and collision handling in C#
- Increasing difficulty / speed over time
- Built and tested for Android

## Tech stack
- **Engine:** Unity (3D)
- **Language:** C#
- **Platform:** Android

## How to run
1. Open the project in Unity (version `<your Unity version, e.g. 2022.3 LTS>`).
2. Open the main scene at `Assets/Scenes/<MainScene>.unity`.
3. Press **Play** in the editor, or build for Android via *File → Build Settings → Android*.

## What I learned
- Procedural generation of game objects at runtime
- Working with Unity's physics, colliders and rigidbodies
- Structuring gameplay code in C# (spawning, scoring, game state)
